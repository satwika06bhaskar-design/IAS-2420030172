AES FILE TRANSFER - SERVER TO CLIENT

Information Assurance and Security - ALM-2

Name: P. SATWIKA REDDY
Roll Number: 2420030172
Section: 11

This is a different human-readable plaintext file for the AES file transfer assignment.
The server encrypts this file using AES-256-CBC and sends the ciphertext to the client.
The client receives the encrypted data, decrypts it using the same AES key, and displays
both the ciphertext and the recovered plaintext.

PyCryptodome is used to implement AES encryption and decryption.
This experiment demonstrates secure server-to-client file transfer.
